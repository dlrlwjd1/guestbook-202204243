# Spec: 미니 방명록
Status: ready-for-agent

## Problem Statement
로그인 없이 이름·메시지·작성 시각을 남기고 글별 비밀번호로 본인 글을 수정·삭제하는 과제를 실제 배포해야 한다.
## Solution
공개 목록과 작성 폼을 한 화면에 제공한다. 각 글의 수정·삭제 버튼을 누르면 비밀번호 입력 대화상자가 열린다. 성공 시 목록을 갱신하고 오류는 화면에 안내한다.
## User Stories
1. 방문자는 이름·메시지·비밀번호를 입력하여 새 글을 남긴다.
2. 누구나 이름·메시지·작성 시각이 포함된 전체 글을 최신 작성 순으로 본다.
3. 글쓴이는 비밀번호를 입력하여 메시지만 수정한다. 이름과 작성 시각은 보존한다.
4. 수정 시 비밀번호가 다르면 내용을 변경하지 않고 오류를 안내한다.
5. 글쓴이는 비밀번호와 삭제 확인으로 자기 글을 삭제한다.
6. 삭제 시 비밀번호가 다르면 글을 남겨두고 오류를 안내한다.
7. 작성·수정·삭제가 성공하면 재조회·새로고침 후에도 유지된다.
8. UI에 개발자의 실제 이름과 학번이 항상 보인다.
9. 스마트폰·데스크톱 및 키보드로 작성과 글 관리가 가능하다.
10. 제출용 공개 GitHub, Vercel, Neon 프로젝트 이름은 모두 guestbook-<학번>이다.
## Implementation Decisions
Next.js App Router, TypeScript, Neon Postgres, Vercel. 작성자 이름 1~30자, 메시지 1~1000자, 비밀번호 4~128자. 이름·메시지의 바깥 공백 제거. 비밀번호 공백은 의미를 보존한다. 한국 시간으로 작성 시각 표시. 편집 시 updated_at을 기록하되 목록 정렬은 created_at을 유지한다. 글 비밀번호는 scrypt(salt 16 bytes, key 64 bytes, N=16384/r=8/p=1) 해시로 저장. 잘못된 비밀번호는 403 응답과 한국어 오류 안내. 로그인·회원가입 없음.
## Testing Decisions
실제 로컬 Postgres를 사용하여 공개 서비스 함수의 CRUD, 잘못된 비밀번호 수정·삭제, 생성일 보존·정렬, 입력 검증, 민감 정보 미노출을 테스트한다. 실제 HTTP 및 브라우저에서 전 흐름·모바일·키보드·다이얼로그 오류를 검증한다. 배포본에서도 작성→조회→오답 거부→수정→삭제를 확인한다.
## Out of Scope
로그인·회원가입·운영자·파일 첨부·비밀번호 찾기·이름 수정·댓글.
