## Standards

문서화된 기준 위반 또는 조치가 필요한 보안 결함 없음.

- 무작위 salt, scrypt, timingSafeEqual 사용.
- 입력은 SQL 매개변수로 전달하며 공개 응답은 비밀번호 관련 필드를 제외.
- 수정·삭제 모두 서버에서 저장된 비밀번호를 검증.
- Vercel에서는 로컬 DB 대체 사용을 거부.
- 메시지는 React 텍스트로 출력하고 오류를 대화상자에 표시.
- 서비스와 브라우저 테스트가 CRUD를 검증.

선택적 판단 1건: `lib/guestbook.ts`의 변환 함수 `entry`를 `toPublicEntry`로 바꾸면 목적이 더 명확할 수 있음. 필수 수정 사항은 아니며 현재 작은 모듈에서 사용 범위가 명확해 유지.

## Spec

조치가 필요한 구현 차이 없음.

- 공개 조회와 작성 시각 내림차순 정렬, 이름·메시지·시간 표시 구현.
- 잘못된 비밀번호는 수정·삭제 이전에 거부하고 한국어 오류 안내.
- 수정은 메시지에만 적용되며 이름·작성 시각·정렬 순서 보존.
- 이기정·202204243 표시.
- 로그인·운영자 기능을 추가하지 않음.
- 검토 시점의 배포는 진행 중이었으므로 공개 배포 검증 결과는 별도 검증 기록에 기재.
